# cfgprism

Конвертер конфигов между форматами **без молчаливых потерь**:
сохраняет комментарии, порядок ключей и форматирование там, где целевой
формат умеет их выразить, и явно предупреждает там, где потеря неизбежна.

> Статус: **Этап 0 — разведка — завершён. Кода пока нет.**
> Архитектура и выбор парсеров зафиксированы в [`docs/DESIGN.md`](docs/DESIGN.md),
> журнал неоднозначностей — в [`docs/DECISIONS.md`](docs/DECISIONS.md).

## Почему не yq / dasel

| | yq | dasel | cfgprism (план) |
|---|---|---|---|
| Комментарии при конвертации | молча дропает (`-o=json`) | отбрасывает на входе (зафиксировано в man) | сохраняет, иначе `Warning` в stderr |
| Порядок ключей | может пересортировать | не гарантируется | всегда сохраняется |
| YAML-якоря → JSON/TOML | раскрывает молча | раскрывает молча | раскрывает + `AnchorExpanded` |
| `--strict` (warning → ошибка) | нет | нет | да |
